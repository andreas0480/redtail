# Narrator

A self-hosted text-to-speech subsystem that turns each daily journal entry
into an MP3 in a Sir-David-Attenborough-style voice. Runs on a separate GPU
machine via a once-daily cron, pushes the resulting audio to production
over SSH, and updates the production database with the new file path.

## What it produces

For each `daily_summaries` row that doesn't yet have a `narration_path`,
the system synthesizes a single MP3 covering the day's narrative summary
*and* its biological-footnote paragraph (joined by a paragraph break). A
typical entry is 80–100 seconds, 150–300 KB.

The species page also has a one-off, ~10-minute narration of the entire
profile, generated by `narrate_species.py` and committed to the repo as a
static asset.

## Setup

Requirements:

- NVIDIA GPU with CUDA 12.1+ driver (tested on RTX 4070 / 12 GB VRAM)
- Python 3.11 (XTTS-v2 is finicky about Python 3.12)
- ~3 GB free disk for the model
- SSH access to the production host with `docker exec redtail`

```bash
cd narrator
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python torch torchaudio \
    --index-url https://download.pytorch.org/whl/cu121
uv pip install --python .venv/bin/python coqui-tts huggingface_hub \
    "transformers>=4.50,<4.55"

# Download the model (~2 GB compressed, ~3.5 GB extracted)
.venv/bin/python -c "
from huggingface_hub import snapshot_download
snapshot_download('drewThomasson/xtts_David_Attenborough_fine_tune', local_dir='model')
"

cd model
unzip -j Finished_model_files.zip "Finished_model_files/model.pth" \
    -d Finished_model_files/
cp Finished_model_files/vocab.json_ Finished_model_files/vocab.json
```

A quick smoke test:

```bash
COQUI_TOS_AGREED=1 .venv/bin/python -c "
from TTS.tts.configs.xtts_config import XttsConfig
from TTS.tts.models.xtts import Xtts
import torch, torchaudio

config = XttsConfig()
config.load_json('model/Finished_model_files/config.json')
model = Xtts.init_from_config(config)
model.load_checkpoint(config, checkpoint_dir='model/Finished_model_files',
                      use_deepspeed=False)
model.cuda()
out = model.synthesize(
    text='The first egg of the season has appeared.',
    config=config,
    speaker_wav='model/Finished_model_files/ref.wav',
    gpt_cond_len=3, language='en')
torchaudio.save('output/test.wav',
                torch.tensor(out['wav']).unsqueeze(0), 24000)
print('Wrote output/test.wav')
"
```

## Usage

The script SSHes into production, queries which `daily_summaries` rows
need narration, synthesizes them locally, and pushes the result back.

```bash
export REDTAIL_HOST=192.168.30.103
export COQUI_TOS_AGREED=1

# All pending days (anything with NULL narration_path)
.venv/bin/python narrate.py

# A specific day (forces regeneration if a narration already exists)
.venv/bin/python narrate.py --day 2026-05-13

# Show what would happen without actually generating
.venv/bin/python narrate.py --dry-run
```

## Cron

A daily run at 00:30 — half an hour after the production system writes the
day's final summary at 23:55:

```cron
30 0 * * * COQUI_TOS_AGREED=1 REDTAIL_HOST=192.168.30.103 \
  /home/belitz/redtail/narrator/.venv/bin/python \
  /home/belitz/redtail/narrator/narrate.py \
  >> /home/belitz/redtail/narrator/cron.log 2>&1
```

If the GPU box is offline at 00:30, the run silently fails and the next
day's run will narrate both days.

## How chunking works

XTTS-v2 has **two independent ceilings** per synthesis call:

- **~400 GPT tokens of input.** Long text fails with an AssertionError.
- **~27 seconds of output audio.** Long text *silently truncates* — you
  get audio that ends abruptly mid-sentence. This is the more dangerous
  failure mode and caught me out for a week.

The narrator always sentence-chunks its input at ~220 characters per
chunk. That produces 12–15 seconds of audio per chunk, well under both
ceilings. Chunks are stitched together with 350 ms of silence between
them, producing audio that sounds like a single continuous reading.

## Performance

On an RTX 4070:

| Step | Time |
|---|---|
| Model load | ~15 s (one-time per invocation) |
| Synthesize 1 summary chunk (~12 s audio) | ~2 s |
| Encode WAV → MP3 (`ffmpeg -q:a 5`) | <1 s |
| SCP + docker cp + DB update | ~1 s per day |

A backlog of 10 days takes about 2 minutes from cold start.

## Licensing and ethical notes

- **XTTS-v2 is non-commercial only** (Coqui Public Model License, "in
  limbo" status per Coqui's own GitHub issue). Personal/hobby use only.
- **The Attenborough voice clone is unauthorized.** Sir David
  Attenborough publicly objected in November 2024 to his voice being
  cloned without consent and called it identity theft. ElevenLabs'
  Iconic Voice Marketplace (launched November 2025) deliberately does
  not include him. This project uses an unauthorized community
  fine-tune from `drewThomasson/xtts_David_Attenborough_fine_tune` for
  a private journal that is not redistributed.

A legally-clean alternative is to use ElevenLabs' "Patrick International"
or "Dan" voice with the v3 model and a hushed-narrator style — you lose
the recognition but you gain the legitimacy.
